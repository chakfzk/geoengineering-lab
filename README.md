# 지구공학 3D 체험실

중학교 3학년을 위한 지구공학 원리 관찰 앱입니다. 『십대가 꼭 알아야 할 기후변화 교과서』(이충환) <자료 4>의 지구공학 기술을 3D 모형과 2D 원리 도식으로 살펴봅니다. 철분 살포와 심층수 끌어올리기를 나누어 모두 12개 항목입니다.

**바로 보기 → `https://<깃허브아이디>.github.io/geoengineering-lab/`**

## 조작

- 왼쪽 목록에서 기술 선택
- **슬라이더**: 장치를 얼마나 작동시킬지 조절 (실제 제거·차단 비율이 아닙니다)
- **작동 전과 비교**: 같은 시점에서 0%와 내 설정을 견주어 보기
- **일시정지**: 시간만 멈춤. 설정과 시점은 그대로 조작 가능
- **입체 / 정면**: 3D 모형과 2D 원리 도식 전환
- **이름 안내**: 모형 위 작은 점(+)에 마우스를 올리거나 누르면 이름 표시. 터치·키보드도 지원
- **실제 사진**: NASA 관측 사진을 출처와 함께 확인 (자연·유사 현상 참고 사진이며 지구공학 실행 결과가 아닙니다)
- 드래그로 회전, 두 손가락(또는 + / −)으로 확대

## 수업에서 볼 만한 지점

- **우주 반사경**: 기울인 거울에 닿은 빛만 나란히 우주로 되튕기고, 나머지는 지구에 도달합니다.
- **해상 구름 밝히기**: 확대 칸의 막대 두 개를 보세요. *물의 양*은 그대로인데 *반사 겉넓이*만 1.6배로 늘어납니다. 같은 물을 잘게 나눌수록 표면이 넓어지는 원리입니다.
- **건물 지붕 반사율**: 50%에 두면 앞줄은 흰 지붕이 되튕기고 뒷줄은 어두운 지붕이 흡수하는 모습이 한 화면에 같이 보입니다.
- **심층수 끌어올리기**: 금색이 영양분입니다. 플랑크톤이 아니라 *영양분*이 올라와 표층 플랑크톤을 키운다는 점이 핵심입니다.

## 실행 (내려받아 직접 열 때)

`index.html`을 브라우저로 더블클릭하면 그대로 실행됩니다. 로컬 서버로 열어도 됩니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

## 만든 방식

Three.js 0.160.1, Lucide 0.468.0, @pmndrs/vanilla 1.25.0 Cloud 모듈과 지구·구름 텍스처를 모두 포함해 **CDN 연결 없이** 실행됩니다. 학교 망에서 외부 접속이 막혀 있어도 동작합니다.

원리 설명을 위해 크기·시간·효과를 단순화했습니다. 기후 예측이나 실제 기술 효과의 정량 모형이 아닙니다.

라이브러리와 사진의 출처·라이선스는 [`assets/SOURCES.md`](assets/SOURCES.md)에 있습니다. 사진은 모두 NASA 공개 자료입니다.
